🌀 Sound Affect — Projeto de RPG com Mecânicas de Voz

Sound Affect é um RPG original atualmente em desenvolvimento, focado em oferecer uma experiência inovadora ao combinar narrativa interativa, mecânicas únicas baseadas em voz e sistemas avançados de controle. O jogo utiliza um motor híbrido que integra Python, Ren’Py e Lua, além de diversas bibliotecas, pacotes e módulos complementares para construir uma estrutura robusta, flexível e expansível.

O objetivo do projeto é criar um RPG onde a voz do jogador não é apenas um acessório, mas parte fundamental da jogabilidade — influenciando decisões, ativando habilidades, alterando comportamentos de personagens e desbloqueando caminhos exclusivos. Para isso, Sound Affect combina:

🔧 Tecnologias Principais

Python → responsável pela lógica principal, sistemas internos e scripts avançados.

Ren’Py → utilizado para narrativa, interface visual, gerenciamento de cenas e estruturação de diálogos.

Lua → empregado para modularidade, sistemas de combate, comportamento de entidades e recursos independentes do núcleo.

Pacotes e motores auxiliares → incluindo ferramentas de áudio, reconhecimento de voz, processamento de sinais e gerenciamento de assets.


🎮 Proposta do Jogo

Sound Affect busca se destacar pela forma como mistura interatividade emocional, respostas dinâmicas e mecânicas sonoras. O jogo pretende oferecer:

Sistema de voz integrado ao gameplay

Narrativa adaptativa baseada nas ações do jogador

Combate com múltiplas camadas e eventos reativos

Mecânicas personalizadas que combinam áudio, escolhas e estratégia

Um mundo imersivo construído para evoluir conforme o estilo do jogador


🌐 Estrutura do Projeto

O desenvolvimento é distribuído em módulos independentes que se comunicam entre si, permitindo que cada parte do sistema — desde o reconhecimento de voz até a interface visual — seja atualizada com segurança e flexibilidade. Isso facilita o trabalho em equipe, possibilita testes mais eficientes e mantém o código organizado.
